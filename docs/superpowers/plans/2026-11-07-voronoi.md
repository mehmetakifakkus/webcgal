# Voronoi Diyagramı: Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** WebCgal'e Delaunay ikiliğinden türetilen Voronoi diyagramını (köşe → kenar adımlı oynatıcı, sayfa, API, dokümantasyon) eklemek.

**Architecture:** Saf geometri `src/geometry/algorithms/voronoi/` altında: `voronoi()` mevcut `delaunay()` ve `circumcenter` üzerine çevrel merkezleri birleştirip ikili kenar/ışınları ve hücreleri kurar; `clip.ts` Liang–Barsky ve Sutherland–Hodgman kırpma; `verify.ts` doğrulayıcı. Oynatıcı altyapısı değişmez; `src/players/voronoiPlayer.ts` `{ points }` alır, iki görsel mod sunar.

**Tech Stack:** Mevcut: Vite 8, React 19, TypeScript, paper.js 0.17.0, Vitest 5 (node + browser), Playwright 1.63, MDX, Netlify.

**Spec:** `docs/superpowers/specs/2026-11-07-voronoi-design.md`. Önceki: `2026-11-07-delaunay-design.md`.
