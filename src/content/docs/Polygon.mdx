As we all know, polygon is a plane figure that is bounded by a finite chain of 2D line segments. Here, [Polygon](/documentation/Polygon) is an object made of closed form of [TextPoint](/documentation/TextPoint)'s.

Each polygon can be repositioned by mouse dragging. Moreover, it is also possible to move each PolygonPoint.

Polygon can be initialized by several ways. You can see details on [createPolygon](/documentation/createPolygon) function documentation page.

## Polygon.draw()

This function clears log screen which located upper-right part of the coding screen. It is on the [playground](/playground) page. This code below first clear the screen, then traverses and prints the polygon points.

```js
var polygon = createPolygon('star');
polygon.draw()
```
