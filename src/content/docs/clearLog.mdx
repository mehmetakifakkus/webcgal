### print(...values)

Writes one line to the output panel: the values, separated by spaces, as `console.log` shows them.

`printLog(...values)` is the same function as `print`.

```js
print('hello', 42, [1, 2]); // hello 42 [1, 2]
printLog(new Point(1, 2));   // { x: 1, y: 2 }
```
