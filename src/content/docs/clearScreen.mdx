This function clears drawing screen. You can experience that on the [playground](/playground) page. This code below first clear the screen, then draw polygon points.

```js
polygon = createPolygon('square'); // create a square shape polygon
polygon.draw();

clearScreen(); // clears all objects drawed before
polygon = createRandomPolygon();
```

It removes what the WebCgal functions drew (points, lines, circles, polygons and the drawings of the algorithm functions). Paper.js items you create yourself, such as `new Path.Rectangle(...)`, stay, and so do the coordinate system of `drawCoordinateSystem()` and what a `Vector`'s `draw()` drew.

### clear()

`clear()` is the same function as `clearScreen()`.
