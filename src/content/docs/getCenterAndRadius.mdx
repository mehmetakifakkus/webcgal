It is a useful function that returns center and radius. drawCircle function can visualise this. Both versions take `TextPoint` objects, `Point` objects, `{ x, y }` objects or `[x, y]` arrays and return `{ center, radius }`, where `center` is a `Point`: the shape `drawCircle` takes.

### getCenterAndRadius2(p1, p2)

The circle that has the segment from `p1` to `p2` as its diameter. Two points version usage is like this:

```js
var points = Points.createRandom(2);

var result = getCenterAndRadius2(points[0].pos, points[1].pos);
drawCircle(result);
```

### getCenterAndRadius3(p1, p2, p3)

The circle through the three points. When they are on one line, it is the circle whose diameter is the farthest pair of them, which encloses all three. Usage is like this:

```js
var ps = Points.createRandom(3);

var result = getCenterAndRadius3(ps[0].pos, ps[1].pos, ps[2].pos);
drawCircle(result);
```
