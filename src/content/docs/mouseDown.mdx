You may want to create apps with user interaction. Therefore, we need to trigger a function to detect user clicks.

Function usage is like this:

```js
var points = Points.createRandom(7);
drawCircle(miniDisc(points));

function mouseDown(point){
   points.push(point); // store point in other 7

   Points.drawPoints(points); // clear olds, draw points again
   drawCircle(miniDisc(points));
}
```

Another function with mouseDown is like this:

```js
var points = Points.createRandom(7);
Points.drawLines(convexHull(points));

function mouseDown(point){
   points.push(point); // store point in other 7

   Points.drawPoints(points); // clear olds, draw points again
   Points.drawLines(convexHull(points));
}
```
