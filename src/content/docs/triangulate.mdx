Splits a simple polygon into triangles: first into y-monotone pieces, then each piece into triangles. The algorithm is explained step by step on the [Polygon Triangulation](/algorithms/triangulation) page.

```js
triangulate(polygon)
```

`polygon` is a `Polygon` object, an array of `TextPoint` objects, or an array of `Point` objects, `{ x, y }` objects or `[x, y]` arrays. The polygon must be simple (no crossing edges); otherwise an error is thrown ("triangulate: the polygon must be simple (no crossing edges)"). Other input throws "expected a Polygon or an array of points (item N is not a point)". Vertices are referred to by their 0-based index in the input order, whichever way the polygon is oriented. The result has these fields:

- `types`: the type of each vertex (`start`, `end`, `split`, `merge` or `regular`).
- `partitionDiagonals`: `[[i, j], ...]`, the diagonals that split the polygon into monotone pieces.
- `pieces`: the monotone pieces, each a list of vertex indices.
- `triangulationDiagonals`: `[[i, j], ...]`, the diagonals that split the pieces into triangles.
- `triangles`: the triangles, each a list of three vertex indices.

`makeMonotone(polygon)` runs only the first phase and returns `types`, `partitionDiagonals` and `pieces`.

Two helpers draw a result:

- `drawDiagonals(polygon, diagonals, color)` draws diagonals as lines; `color` defaults to `'red'`.
- `drawTriangles(polygon, triangles)` draws the triangles.

```js
drawCoordinateSystem();
polygon = createRandomPolygon();
polygon.draw();
var result = triangulate(polygon);
drawDiagonals(polygon, result.partitionDiagonals, 'red');
drawDiagonals(polygon, result.triangulationDiagonals, 'blue');
console.log(result.triangles.length + ' triangle(s), ' + result.partitionDiagonals.length + ' partition diagonal(s)');
```
